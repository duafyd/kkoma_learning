# 모모의 동네 · 첫 출시 주문 80개

각 행은 아이에게 한 번에 제시할 주문 한 장이다. ID에 가게(F 과일 가게, B 빵집), 만 나이, 영역(K 한글·E 영어·M 수학·O 관찰·P 규칙), 주문 번호를 넣었다. ID는 보기 순서가 바뀌어도 유지한다. 아래 대사는 녹음용 첫 부탁이다. 화면에는 같은 말과 시각 단서를 둔다. 도움을 보고 끝낸 경우도 다음 장으로 갈 수 있다.

**제작 상태.** 0.5에서는 F4-K1·E1·M1·M2·O1·P1에 대응하는 여섯 장면을 실행할 수 있다. 구체적인 대사·조작·완료 연출은 [과일 가게 콘티](FRUIT_ROUND.md)를 따른다. 나머지 행은 제작할 문항이다. 연필 서랍과 세 장 모드용 변형은 기본 80개와 별도로 센다.

## 제작자가 한 장을 구현할 때

주문 ID에 시작·힌트·완료 대사, 보기와 정답, 결과 소품, 소리 옵션, 입력 방식, 도움 사용 여부를 묶는다. 위 표의 부탁이 첫 음성이다. 의미 있는 답은 그림·개수·규칙·글자 경로로 정의한다. 오답이면 보기를 유지하고 표에 적힌 단서를 한 번에 하나씩 보여 준다. 완료는 결과 소품에 이름이나 수를 붙이고 모모가 그 결과를 짧게 말하는 시점이다.

- **듣고 고르기**에서 소리를 끄거나 그림 단서를 요청하면 목표의 그림과 수량 점을 펼친다. 이후 정답은 그림을 보고 해결한 것으로 기록한다. 소리 켜짐이 첫 실행 기본값이다.
- **옮기기·배열**은 같은 목표를 탭만으로 달성할 수 있게 한다. 위치가 하나면 물건을 누르고, 여럿이면 물건과 자리를 차례로 누른다. 오답과 손 떼기에도 이미 맞힌 칸은 보존한다.
- **쓰기**는 직접 쓴 구간과 모모가 도운 구간을 구분한다. 학습 목표가 여러 획이면 획 경로와 순서를 제작 데이터에 명시한다. 연필 서랍의 연령·과목별 세 모양은 [출시 명세](RELEASE_SPEC.md)에 있다.
- **변형 작성 예**로 F4-M1의 사과 두 개를 배 세 개로 바꿀 때는 주문 음성, 주문표 칸, 실물 수, 힌트와 완료 수량도 함께 바꾼다. 내용 편집 단계에서 각 가게·연령·영역에 세 장 모드용 변형을 준비한다. 같은 배경에서 보기 위치만 바꾼 장은 새 주문 수에 더하지 않는다.
