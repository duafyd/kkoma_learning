## 이번 후속 작업의 범위

새 콘텐츠를 검수 완료로 늘리기 전에, 잘못된 듣기 완료 기록·동시 입력·동시 작품 저장 등 실제 발견된 안정성 문제를 수정했다. 전체 완성도 수치는 요구사항별 가중치로 측정한 값이 아니므로, 테스트 개수 증가만으로 출시 진행률을 올리지 않는다.

## 이어서 할 일

1. 문항을 유형별로 보강하고, 쉬운 대체 문제와 명확한 정답 조건을 콘텐츠 테스트로 검증.
2. 전문가 검수에 넘길 필기·발음·문항 목록을 정리하고, 검수된 콘텐츠만 활성화.
3. Android 연결 문제 및 기기 검증은 서명 없이 유지한다는 결정을 준수하는 범위에서만 진행. 키 생성·서명을 다시 요청하거나 자동 실행하지 않음.
