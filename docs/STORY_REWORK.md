# 별조각 수집 이야기 개편 (2026-10-17)

별빛은 별조각이 내는 빛이다. 플레이어가 모으는 물건은 도서관 책등의 빈칸에 끼우는 **별조각 12개**다. 화면 상단의 수집 수와 그림 안의 12칸짜리 수집책이 같은 저장 진도를 표시한다.

각 화는 조각의 위치를 먼저 보여 주고, 접근을 막는 문제를 설명한다. 퀴즈·필기는 그 문제를 해결하는 준비 단계다. 준비가 모두 끝나면 조각이 노랗게 바뀌며, 아이가 조각 또는 '별조각 담기'를 눌러 책에 담는다. 다음 장면 버튼도 수집을 마무리하는 대안이다. 중간 활동 성공을 최종 조각 회수와 구분해 말한다. 이미 담은 조각을 다시 담으라고 안내하지 않는다.

| 화 | 눈앞의 문제 | 돕는 행동 | 조각을 얻은 뒤의 연결 |
|---|---|---|---|
|1|책 밑에 낀 조각|같은 별 모양 찾기, 받침과 숫자 길 만들기|조각 뒤 꽃문 지도|
|2|닫힌 꽃잎 안의 조각|모음 소리 자물쇠와 꽃길 표지 잇기|자음 나무로 이어진 꽃길|
|3|가지에 걸린 조각|같은 자음 열매·씨앗 바구니와 이름표|씨앗 꾸러미를 보낼 기차역|
|4|역 지붕 위의 조각|기차 칸의 소리 표지를 고쳐 승강장 비우기|사다리로 조각을 내리고 등대로 출발|
|5|어두운 바위틈의 조각|A 등불과 빛길·이름표 찾기|귀환 길의 숫자 다리|
|6|다리 건너편 조각|빈자리 돌 세 개 놓기와 수량 표지 확인|색이 사라진 정원|
|7|표지가 섞인 화단의 조각|색·모양·패턴 정리, 가능한 경로에서 정원 그림 저장|바람 언덕에서 부르는 휙휙|
|8|바구니 밑의 조각|글자·숫자 표지 분류와 C 손잡이, 휙휙이 함께 정리|남은 지도의 숲길|

연령에 따라 4/6/8/10장면의 기존 경로를 유지한다. 만2세의 무정답 선택은 친구가 준비를 돕는 짧은 경로다. 도움 통과·쉬운 문제도 같은 이야기 결과를 만들며, 글자를 정확히 쓰지 못했다는 이유로 영구적으로 막지 않는다.

## 코드와 저장

- 실제 앱의 대사·목표는 `lib/features/story/data/chapter_direction.dart`가 원본 에피소드의 장면/퀴즈/삽화 데이터에 적용된다. 대사를 바꿀 때 이 파일을 수정한다. `storyEpisodes`가 실행·검토·음성 대본의 공통 카탈로그다.
- `StoryQuest`는 실제 연령별 장면과 State Machine의 저장된 위치/성공 상태에서 준비 정도를 계산한다. 렌더러가 보상을 자체 지급하지 않는다.
- 새 회수 기록은 기존 `flags` 안의 `book-fragment-<화>: collected`다. 과거 `completed` 화는 이미 수집한 것으로 읽고 기존 진도·분기·필기·그림은 보존한다.
- `StoryQuest.collectedFrom`이 과거 완료와 새 회수 기록을 중복 없이 합쳐 이야기/작품·모험 지도에서 같은 집계를 사용한다. 화 완료 전 회수도 지도 수집책의 같은 번호에 표시하고, 지도 열기/표지 미리보기는 저장을 변경하지 않는다.
- 도입 소품 찾기는 준비 행동이다. 꽃문 열기·정원 복구·조각 회수·귀환이 본 미션보다 먼저 끝났다고 말하지 않는다. 같은 장면에서 조각을 회수하면 자동 읽기도 새 결과를 한 번 읽는다.
- Flame `StoryQuestGame`은 수집책·장소별 장애물·잠긴/준비된 조각·저장 뒤의 유한 이동·마지막 12조각 책을 그린다. 기존 장면별 Flame 소품 선택/돌다리/별 배치와 결합한다. 배경·캐릭터는 기존 삽화와 Flutter 합성을 재사용한다.
- 수집 가능 조각은 탭과 접근성/버튼 대안을 제공한다. 스크롤 중에도 상단 수집 수가 남는다. 동작 끄기·백그라운드·복원은 진행 상태를 그대로 표시하고 보상 연출을 다시 시작하지 않는다.

## 성공과 필기

학습 정답·필기 완료는 저장된 상태 전이 뒤에만 번들 성공 효과음을 요청한다. 화면에는 큰 체크·별·성공 안내가 남는다. 다음 문제에서 사라지며, 복원·연타·저장 실패가 새 성공 소리를 만들지 않는다. 효과음0 설정을 존중하고 음성 실패에도 시각 피드백을 유지한다.

필기는 짧은 획의 허용 폭과 끝점 여유를 넓혔다. 길이·진행 방향·경로 피복은 유지하면서 순간적인 흔들림을 모두 실패로 처리하던 최악 한 점 비교를 제거했다. 시뮬레이션된 오차·부분 완료와 기존 전체 경로·낙서·탭·역방향 검사를 함께 실행한다. 실제 아동의 손가락 난이도 판정은 검증 대기다.

## 검수 범위

새 배경·캐릭터 그림/긴 걷기·음소 립싱크·AI 연기 음원을 제작한 작업이 아니다. 실제 등록 음원은0개이고 TTS 대안이다. 개연성·학습량·필순에 대한 교육자 승인, 아동 관찰과 실제 기기 청취/필기/성능 검증은 남아 있다. 최종 실행 결과와 로컬 APK는 `PROGRESS.md` 상단을 따른다. Git/APK 공개는 별도 요청 때만 한다.
