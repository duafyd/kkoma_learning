# 콘텐츠 정합성 검토 기록 (2026-10-16)

개발자가 데이터와 실제 진행 규칙을 대조한 결과다. 교육자 승인·실제 청취·아동 관찰 결과가 아니며 외부 검수 상태는 계속 pending이다.

| 대상 | 발견 | 수정과 확인 |
|---|---|---|
| h-bag / h-tree | ㄱ/ㄴ 선택을 요구하면서 첫 '글자'로 안내 | 첫 '자음'으로 수정. 선택지/정답/ID는 유지하고 대본 JSON/CSV도 같은 원문으로 재생성 |
| ep1~12 explore 문항12개 | 실제 모든 선택 통과지만 카탈로그에는 answer0 한 개가 정답처럼 표시. 힌트도 한 선택만 강조 | `isExploration`으로 규칙 명시. 유효 선택 모두 수용/범위 밖 거절, 양쪽 힌트 동등. JSON 정답 null·CSV 정답 빈칸/허용 선택 모두 표시 |
| 연령별 장면 검토 목록 | 일반/탐색/모든 분기를 같이 나열해 실제 노출 문제와 구분 어려움 | StoryMachine의 연령·분기·대체 문제·도움 선택을 사용. primary/support/branches와 각 acceptedIndices를 기록 |
| 필기 도움 문제 | 런타임에 만들어지는9개가 기존118문항 검토에서 누락 | 실제 도움 정책을 실행해 총127개에 포함. 예: story-support-n-1, story-support-h-ㅏ, story-support-e-A. 모든 참조가 카탈로그에 존재하는지 검사 |
| 중복 ID 처리 | Map에 대입하며 다른 내용도 조용히 덮어쓸 수 있음 | 내용이 같은 공유 문제는 허용하되 다른 내용은 오류로 중단. 그림 ID/배치/세기/대체 문제/안내까지 비교 |
| 그림 선택 모호성 | 글자 선택지 중복만으로는 똑같은 그림이나 수량 정답 불일치를 검출하지 못함 | 실제 glyph 배열 중복 및 count형 수량 정답의 유일성을 검사. 의도적으로 잘못 만든 fixture로 거절 확인 |

문항127개는 서로 다른127개 학습 개념을 의미하지 않는다. 과목·스토리·도움 문제와 재사용 변형을 합친 검토 단위다. 필순의 공인 여부, 손글씨 적절성, 문제의 교육 효과와 실제 아동 난이도는 이 검사로 확정하지 않는다.

추가 배포 검사: StorySnapshot이 ID로 복원하므로 에피소드/장면 ID 중복·빈/공백 ID, 연령별 빈 경로, 범위 밖 단계, 런타임 전용 phase의 콘텐츠 사용, 누락 퀴즈/필기 ID/분기 flag와 빈·중복 선택을 별도로 거절한다. 의도적으로 손상시킨 fixture와 실제12화 카탈로그의 새9개 검사로 확인하며 교육 검수 상태는 변경하지 않는다.
