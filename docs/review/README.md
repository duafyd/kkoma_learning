# 콘텐츠 검토 자료

이 자료의 자동 검사 통과는 교육 전문가 검수나 아동 사용성 관찰을 뜻하지 않는다. 모든 외부 승인 필드는 `pending`이며 검수자·날짜·근거 없이 승인으로 바꾸지 않는다.

- `learning_review.json`: 기존 학습 122항목과 별도 손가락 준비 운동 6항목의 좌표·획 순서·이름·예시.
- `hangul-{1,2}.png`, `english-{upper,lower}.png`, `numbers.png`, `prewriting.png`: 획마다 다른 색, 시작점, 순서 번호를 표시한 실제 경로. a/g는 한 층 손글씨 형태다.
- `content_review.json`: 실제127문항/선택 규칙/그림, 지원 문제, 분기와 4연령×12화의 장면 목록. 기존118개에 런타임에서 만드는 필기 도움 문제9개도 포함한다.
- `quiz_review.csv`: 교육자가 문항별로 검토할 수 있는 표. `answer_mode=exploration`인12문항은 단일 정답 칸을 비우고 `accepted_options`에 모든 선택지를 기록한다.
- 음성의 이름·발음·캐릭터 연기 검토는 별도 `../audio/voice_scripts.json`과 `STORY_DIRECTION.md`를 사용한다. 이번 요청에서는 음원을 제작하거나 청취하지 않았다.

## 개발자가 수행한 범위

문항 검토 자료 schemaVersion2는 `StoryMachine`으로 실제 노출을 선택한다. 각 장면의 `primary`는 기본 문제, `support`는 도움 문제이며, `branches`는 9화 길/12화 방 등 flag별 실제 문제다. 각각의 `acceptedIndices`는 해당 연령에서 통과하는 선택 인덱스다(만2세는 도움 문제에서도 모든 유효 선택을 받아들이는 기존 정책 유지). 만2세의 탐색 대사와 연령별 대체 문제도 실제 진행 규칙을 따른다. 일반 문제와 탐색 문제·모든 분기 문제를 한 목록에 섞어 실제 노출로 표시하지 않는다. 문항 카탈로그에는 재사용될 수 있는 모든 원본도 포함한다.

동일 ID에 서로 다른 내용이 있으면 내보내기를 중단한다. 빈/중복 선택지, 선택 수와 그림 수 불일치, 같은 그림을 다르게 이름 붙인 선택지, 그림 세기 정답과 수량 불일치를 검사한다. 한글 h-bag/h-tree의 ㄱ/ㄴ 선택은 '첫 자음'으로 안내한다. 문항 ID·정답 인덱스·저장 형식은 유지한다. 상세 발견/조치는 [FINDINGS.md](FINDINGS.md)에 기록했다.

128개 경로의 유한 좌표/캔버스 범위, 모든 연령의 완전 경로 수용과 부분 획/탭/화면 가로지르기 거절을 검사한다. 점 찍기만 전용 Strategy로 탭을 받는다. 25개 영문/숫자 모양의 곡선은 기존 획 수·순서·시작/끝점을 보존해 부드럽게 만들었다. 실제 저장된 완료 획은 그대로 유지한다. 곡선 개선을 필순의 공인 검증이라고 보고하지 않는다.

## 교육자·보호자가 확인할 항목

1. 한글 필순·글자 구성, 영어 손글씨 형태와 대소문자, 숫자 모양의 적절성.
2. 글자 이름과 대표 소리/낱말이 섞이지 않는지, 실제 음원의 발음.
3. 각 그림 문제의 정답이 하나인지, 화면의 배치가 답을 모호하게 만들지 않는지.
4. 만 2세의 무정답 탐색·큰 터치, 3~5세의 판정과 도움 경로가 아이의 실제 수행 수준에 맞는지.
5. 에피소드별 목표·인과 관계·휙휙의 사과/협력 메시지, 실제 활동 시간과 아이의 흥미/피로.

확인 기록 형식: `항목 ID / 검수자 / 날짜 / 결과(수정·승인·보류) / 근거 / 수정 후 재확인`.
