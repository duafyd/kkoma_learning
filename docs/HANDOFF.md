# 꼬마런닝 · 완성본 개발 인수인계

**2026-11-28 · Godot 0.7 기기 검토용 APK** · 저장소 `duafyd/kkoma_learning` · 브랜치 `prototype/worksheet`

- **실행 범위**는 연령 첫 설정·보호자 최근 활동, 독립 한글·영어·숫자와 쓰기 전용 모드, 과일 가게·빵집, 이어하기·마무리 진열대입니다. 첫 실행은 음성과 효과음 켜짐입니다. 갤럭시탭 가로에서 한 손가락으로 조작합니다. [놀이마당](preview/play-menu-07.jpg) · [빵집](preview/bakery-07.jpg) · [한글 쓰기](preview/writing-07.jpg)
- **콘텐츠**는 `godot/activity_catalog.json`에 기본 가게 주문 80개, 연령별 따라 쓰기 36개, 독립 과목 추가 활동 12개가 있습니다. `catalog_card.gd`에서 보기, 담기, 배열, 시각 도움, 완료 피드백을 구현합니다. `trace_two.gd`의 경로는 여러 획을 순서대로 진행합니다. 대사는 `sound/catalog`의 오프라인 A 합성음이며 주문 정의의 `voice`로 연결합니다. 중복 대사는 클립을 공유합니다.
- **진입·편성**은 `round.tscn`과 `round.gd`, `round_deck.gd`가 담당합니다. 연령을 바꾸면 진행 중인 판은 그 판의 연령으로 마치고 다음 판부터 새 설정이 적용됩니다. 가게는 다섯 영역을 한 번씩 제시하며 쓰기는 최대 한 장입니다. 최근 제시한 문항과 도움을 받은 문항의 유사 목표를 다음 편성에 사용합니다.
- **호환**은 `user://fruit_round.cfg`의 기존 0.5/0.6 덱을 완료할 때까지 원래 장면으로 처리하고 새 판부터 카탈로그를 사용합니다. 놀이와 일반/쓰기 모드는 진도를 따로 저장합니다. `preferences.cfg`는 기존 음소거 설정을 읽습니다.
- **검증**은 아래 명령으로 재현합니다. 카탈로그 검사는 128개 활동의 시작 음성·오답·힌트·완료와 두 가게 편성을 확인하고, 나머지는 기존 사과 조작·과목별 왕복·이전 저장을 검증합니다. 스토어 배포용 서명과 아동 대상 갤럭시탭 실기 관찰은 후속 검토입니다.
- **다음 작업**은 [작업 장부](PRODUCTION_PLAN.md)의 실기기 검수입니다. 만 2~3세와 4~5세가 소리를 듣고 시작하는 곳, 손가락에 가려지는 획, 빵집 수량 조작, 오프라인 재실행을 관찰하고 막히는 장면을 수정합니다. 장면별 음성 톤과 문항 교육 검토도 이때 반영합니다.

```sh
godot --headless --editor --path godot --import
godot --headless --path godot --script res://tests/catalog_flow.gd
godot --headless --path godot --script res://tests/subject_routes.gd
godot --headless --path godot --script res://tests/round_flow.gd
godot --headless --path godot --script res://tests/tap_flow.gd
```

0.7의 회귀 검사 네 종은 실패 0건입니다. 서명은 0.6 APK와 일치합니다. 원격 APK를 다시 받아 SHA-256을 대조했고, APK의 `assets/` 아래를 별도 Godot ZIP 팩으로 열어 128개 카탈로그 검사도 실패 0건으로 완료했습니다. 이 검사는 패키지 리소스와 실행 코드를 확인하며 Android 실기기 설치 기록은 앞으로 추가합니다. APK SHA-256은 `a758963dd5ab800c8c601ecadff1ce57557fe6765c5dc2c7935ae857c15d9048`입니다.

새 채팅에서는 **duafyd/kkoma_learning의 prototype/worksheet 최신 브랜치에서 docs/HANDOFF.md와 docs/PRODUCTION_PLAN.md를 읽고 1.0을 이어가**라고 요청하면 됩니다.

## 이전 버전 · 0.5 과일 가게 개발 기록

- `godot/project.godot`의 시작 장면은 `round.tscn`입니다. `round.gd`가 입구·편성·저장·멈춤·진열대를 연결합니다. `market.tscn`은 기존 사과 담기, `fruit_card.gd`는 새 과목, `trace_two.gd`는 한 손가락 쓰기를 담당합니다.
- [여섯 장면 콘티](FRUIT_ROUND.md)를 기준으로 만 4세 대표 활동을 제작했습니다. 첫 판에는 사과 담기가 나오고 다음 판에는 숫자 2 쓰기가 나옵니다. 이후 판도 두 수학 활동을 교대합니다. 현재 각 영역의 대표 문항은 고정이고 과목 순서와 보기 배치가 바뀝니다.
- APK에 A 목소리로 만든 한국어·영어 주문과 피드백을 넣었습니다. 직접·도움·건너뜀 결과와 다음 주문 위치는 `user://fruit_round.cfg`, 음소거는 기존 `user://preferences.cfg`에 보관합니다. 다시 실행하면 입구에서 시작합니다. 진행 중인 장은 같은 보기로 처음부터 다시 시도합니다.
- Godot에서 `godot --headless --path godot --script res://tests/round_flow.gd`로 두 판 완주, 오답, 탭·놓기·쓰기, 재실행, 멈춤·건너뛰기와 무음을 확인합니다. 기존 사과 장면의 상세 입력 테스트는 아래에 있습니다. [실행 화면](preview/round-word.jpg) · [따라 그리기](preview/round-trace.jpg)
- 다음 검토는 갤럭시탭에서 손가락이 숫자 2의 다음 구간을 가리는지, 아이가 말풍선과 시범만 보고 행동을 시작하는지, 효과음과 발화가 함께 들리는지 확인하는 것입니다. 제작은 [완성본 작업 장부](PRODUCTION_PLAN.md)의 순서로 진행하며 기기가 준비되면 관찰 결과를 반영합니다. 80개 주문은 출시 목표입니다.

## 확정된 시각 콘셉트 · 갤럭시탭 가로 / 만 2~5세

2026-11-27 사용자가 캐릭터와 배경 조합을 선택했습니다. 아래 기준은 후속 포즈와 학습 장면에도 적용합니다.

- **모모** — “뿌옇고 파스텔 안 된다고 2~5세가 할 거라고” 요청 직후 나온 투명 배경의 2D 인사 포즈. 둥근 볼, 크림색 앞머리, 반짝이는 갈색 눈과 짧은 팔다리. 살구빛 주황 털, 노란 목수건, 짙은 청록 앞치마와 배 모양 주머니. 화면 왼쪽 앞발을 들어 인사합니다.
- **가게 배경** — 이어진 “배경 약간만 더 단순하게 … 윤곽선도 조금” 요청에서 나온 마지막 단독 배경. 오른쪽에는 주황·크림 차양과 청록색 가게, 사과 상자와 배 바구니가 있습니다. 왼쪽의 굽은 길은 모모가 들어설 자리입니다. 둥글게 묶은 나뭇잎, 성긴 길 무늬, 사물색을 따라가는 가는 윤곽선이 기준입니다.
- **색과 화면 구성** — 중간 채도의 맑은 색면과 부드러운 명암으로 얼굴과 물건을 구분합니다. 학습 장면에서도 배경의 세부 묘사보다 모모의 표정과 아이가 누를 물건이 먼저 읽히도록 합니다.

이 미술 기준은 시작 메뉴, 과목 선택, 활동, 힌트와 완료 화면까지 공통으로 적용합니다. 각 화면은 장소와 소품을 바꿀 수 있으며 모모의 비율, 색, 윤곽선, 터치에 반응하는 방식은 일관되게 설계합니다. 실행 장면은 Godot 4.7.2와 GDScript로 제작했습니다. 1.0은 이 Godot 프로젝트에서 이어 제작합니다.

새 채팅의 시각 기준은 [게임용 모모](../godot/art/fox.webp), [게임용 가게](../godot/art/shop.webp), [실제 실행 화면](preview/round-word.jpg)입니다. 현재 저장소의 `art/`와 8초 영상은 이전 에셋 검토본입니다. Godot에서는 승인 이미지를 참조해 다시 제작한 게임용 리소스를 godot/art에 보관합니다.

## 0.4부터 유지하는 사과 담기 장면

- 사과 담기 단독 장면은 `godot/market.tscn`입니다. 1280×800 기준의 가로 2D 장면에 모모, 과일 가게, 큰 사과 두 개, 바구니를 배치했습니다. 화면 비율이 다르면 비율을 보존해 표시합니다.
- 사과를 탭해 자동으로 담거나 바구니 가까이 끌어 놓을 수 있습니다. 목표 밖에 놓거나 터치가 취소되면 원래 자리에서 다시 시도합니다. 중복 탭은 한 번만 셉니다. 그림 주문표와 동작 시범을 항상 제공하며 음소거 상태에서는 ‘다시 보기’로 시범을 재생합니다. 소리 설정은 다음 실행에도 적용합니다.
- `godot/sound`에 한국어 합성 음성 다섯 개와 효과음이 있습니다. A 목소리(Supertonic 3 F1)는 임시 음성으로 유지하고 최종 교체는 추후 진행합니다. 0.3은 같은 A 녹음 다섯 개의 길이를 대사별로 0.1과 0.2의 중간에 맞췄습니다. 주문은 1.35초, 칭찬은 1.58초입니다. 유성음의 음높이를 구간별로 조정해 부탁할 때 말끝을 살짝 들고 칭찬은 부드럽게 내려 마칩니다. 중저역을 약간 보강하고 날카로운 고역을 줄였습니다. APK에서 오프라인으로 재생합니다. [0.3 청음](preview/voices/momo-a-warm.mp3) · [모델과 버전](https://huggingface.co/supertone-oss-archive/supertonic-3/tree/aafc6e32416a594460b32413efc49d7fe4ce6d46)
- 코드 검증은 Godot 에디터 임포트 후 `godot --headless --path godot --script res://tests/tap_flow.gd`로 재현합니다. 반복 탭, 연속 탭, 상자 터치, 끌어놓기 성공·실패·취소, 탭과 끌기 혼용, 한 번 더 놀기, 음소거 중 시범과 재실행 후 소리 설정 복원을 검사합니다. 실행 화면은 docs/preview/apple-order.jpg 및 apple-done.jpg에 보관합니다.
- Android SDK와 디버그 키를 설정하고 godot/build 디렉터리를 만든 뒤 `godot --headless --path godot --export-debug "Galaxy Tab"`으로 빌드합니다. 브랜치의 trial/momo-apple-arm64.apk는 테스트 설치용입니다. 서명 검증을 통과했으며 갤럭시탭에서의 설치·프레임·스피커 음량과 아동 사용성은 실기기 확인 대상입니다.

## 보관된 브라우저 실험판에서 확인한 경험

| 영역 | 만 2~3세 활동 예 | 만 4~5세 활동 예 |
| --- | --- | --- |
| 한글 | 들은 낱말에 맞는 그림 찾기, 이름표와 그림 맞추기 | 첫 글자 채우기, 두 개를 주문하는 짧은 글 읽기 |
| 영어 | 영어 낱말을 듣고 물건 고르기 | 영어 이름표 고르기, 만 5세 영어 수량 주문 듣기 |
| 수학 | 하나·둘 대응, 수 세기와 많고 적음 | 물건을 더 담거나 빼서 주문 수량 완성하기 |
| 관찰 | 견본과 같거나 다른 그림 찾기 | 두 물건의 종류와 좌우 순서 비교하기 |
| 규칙 | 한 종류의 반복에서 두 종류의 교대로 | 두세 종류가 반복되는 배열의 빈칸 채우기 |

과일 가게와 빵집은 각각 네 가지 물건을 사용합니다. 두 가게는 공통 활동 구조를 씁니다. 혼합 모드는 다섯 과목을 한 번씩 섞고 직전 판과 다른 과목으로 시작합니다. 가게·나이·과목별로 물건 4종과 변형 2종의 조합을 한 바퀴 쓸 때까지 재추첨하지 않습니다. 나이에 따라 같은 방식의 문항이 나올 수 있습니다. 보기의 위치도 섞습니다.

브라우저 저장소에는 연령과 가게, 최근에 **제시한** 조합과 직전 시작 과목을 기록합니다. 학습 도중 놀이방으로 돌아가도 이미 본 조합은 기록에 포함됩니다. 새로 열면 놀이방부터 시작합니다. 저장소를 사용할 수 없는 환경에서는 현재 열린 화면 안에서만 기록을 유지합니다.
