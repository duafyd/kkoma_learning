# 《별빛 도서관》 음성 연기 제작 지침

목표는 문장을 정확하게 읽는 기기 TTS가 아니라, 아이와 대화하는 성우의 따뜻한 그림책 연기다. 실제 성우 또는 표현력 있는 AI로 **미리 제작한 음원**을 오프라인으로 번들한다. 현재 실제 녹음은 0개이며 이 문서와 제작 도구가 음원 제작을 대신하지 않는다. 성우 섭외·유료 API·결제·외부 대본 전송은 별도 승인 없이 실행하지 않는다.

| 역할 | 연기 방향 | 피할 것 |
|---|---|---|
| 모아 | 포근하고 침착한 길잡이. 설명보다 아이에게 말을 건넨다 | 모든 문장을 똑같이 올리는 안내 방송 톤 |
| 루루 | 호기심 많고 생동감 있는 친구. 발견·실수·기쁨의 차이를 들려준다 | 고함, 과장된 유아어, 계속 들뜬 말투 |
| 토토 | 든든하고 차분하다. 수량 사이 여유를 주고 또렷하게 센다 | 음성을 단순 배속으로 늘이기, 지나치게 낮고 둔한 목소리 |
| 휙휙 | 가벼운 장난기. 사과할 때는 진심과 함께하고 싶은 마음 | 악당 웃음, 무서운 효과, 비난·벌의 어조 |
| 학습 안내 | 소리·이름·대표 단어를 구분하는 명확한 발음 | 알파벳 이름과 단어 첫소리 혼동 |

## 제작 및 검수 순서

1. `dart run tool/export_voice_scripts.dart`와 `dart run tool/export_story_studio.dart`로 인물·감정·장면·정확한 파일 ID가 있는 제작 자료를 생성한다.
2. `story_studio.json`의 인물별 `auditionIds`를 시연한다. 차분함·호기심·성공·사과를 비교하고 동일 캐스팅을 유지한다.
3. 1화의 실제 대사·질문·성공 음원부터 제작해 앱에서 듣는다. 캐릭터 간 음량과 대사-효과음 균형이 안정된 다음 2~12화로 확장한다.
4. 원문만 발화한다. 감정·캐릭터 지시문은 읽지 않는다. 문장 사이 약 350~550ms, 질문 뒤 약 600~900ms 여유를 기본으로 장면에 맞게 조절한다. 성공은 결과를 함께 기뻐하며 과하게 외치지 않는다.
5. PCM16 mono 16~48kHz WAV, 한 파일 60초 이하, 효과음·음악 없는 원본으로 납품한다. 파일명은 정확한 ID를 사용한다. 같은 말이라도 다른 인물/장면의 파일로 대체하지 않는다.
6. `export_story_studio.dart`의 RMS·sample peak·무음/클리핑 경고를 확인하고 직접 청취한다. sample peak와 RMS는 true peak/LUFS 또는 성우 연기 평가가 아니다. 자동 경고가 없다고 검수 완료로 간주하지 않는다.
7. 원문·인물·발음·호흡·놀라게 하지 않는 음량을 사람이 검수한 다음 `prepare_recordings.dart`, `--check`, 콘텐츠 감사, Android 청취를 수행한다. 기존 등록 음원의 원문·언어·인물 변경은 재제작과 재검수를 거친다.

## 앱 연결

스토리 자동 읽기와 다시 듣기는 `StoryMachine.narrationId`의 장면별 녹음 ID를 요청한다. 녹음의 ID·원문·언어가 모두 맞아야 재생한다. 같은 원문을 다른 캐릭터 음원으로 채우지 않는다. 누락/재생 실패에는 현재의 기기 TTS를 임시 대안으로 유지한다. TTS의 속도나 음높이를 바꾸는 것을 성우급 음성 제작으로 보고하지 않는다. 화면 이동·음성 재요청·백그라운드 취소 규칙은 그대로 적용한다.

제작 현황과 캐스팅은 `story_studio.json`에 기록되지만 사람의 실제 승인 상태를 자동으로 만들어 넣지 않는다. 실기기 청취는 사용자 지시대로 마지막 검증에 남긴다.
