최신 로컬 스토리/성공/필기 재개편: 격리 에뮬레이터에서 **5개 통과**(22초, docs/rework-android.log), debug35.4초/설치1.38초. 새 조각 직접 터치·1/12 표시·중복 저장 방지·DB 재개를 기존4개에 추가했다. 고유한 테스트 DB만 사용하고5580만 종료했다. 무음 설정이므로 실제 효과음 청취나 유아 손가락 판정 검증을 대신하지 않는다. 나중에 실제 기기에서 정답/획별/완성 소리, 효과음0, 성공 안내의 가독성, 새 허용 폭의 손가락 시도, 조각/소품의 탭과 수집 이동·12칸 완료·회전/재개를 확인한다. 새 로컬 서명 APK는1.0.0(214329986), docs/story_rework_build.json에 기록했다. 이 로컬 변경은 아래 공개 APK에 아직 포함되지 않았다.

2026-10-17 최신 공개 APK는 **1.0.0(214325690)**이며 다운로드/해시는 docs/published_build.json을 따른다. 전체475개/서명·공개 파일 검증 완료. 이번 추가는 카탈로그/배포 검사이며 아래 Android4개는 직전 단계 결과다. 실제 태블릿 새 설치/업데이트·청취·필기·프레임/메모리·재부팅은 여전히 대기이고, 기존 앱을 삭제하지 않고 같은 서명의 업데이트로 검증한다.

## 2026-10-16 에뮬레이터 확인

최신 스토리 ID 검사: 격리 KkomaPolish5580에서 통합4개 통과(23초, docs/story-identity-android.log). 옛 숫자 문서 무변경 읽기·새 ID 저장·DB 닫기/재개 후 유효 ID/틀린 숫자 복원·지원/선택·힌트/성공 다시 저장·최종 DB 재개와 이전3개 흐름을 확인했다. 부팅51.2초/debug56.2초/설치1.43초. 테스트용5580만 종료하고 기존5554 offline/실기기는 그대로 유지한다. 고유 테스트 DB만 사용한다. 실제 릴리스 업데이트·잠금·OS 종료/재부팅 뒤에도 같은 ID가 이어지는지는 최종 기기 검사에 남긴다.

최신 이어하기 검사: 격리 KkomaPolish에서 **통합3개 통과**(`docs/resume-android.log`). 새 SQLite DB의 빈/403키 조회(400+3)·DB 재개·홈에서 문항/힌트2 바로 복원·필기 다음 획 복원·읽기 후 원본 유지와 기존 두 흐름을 확인했다. 부팅43.2초/debug34.8초/검사20초. 종료 후5580만 종료했고 기존5554는 건드리지 않았다. 나중에 실제 기기에서 새 홈 카드의 탭/글자 확대·업데이트 전후 문항/필기 재개·초기화 완료 후 카드 제거도 확인한다.

최신 보호자 보완 검사도 격리 KkomaPolish에서 **통합2개 통과**(`docs/parent-curriculum-android.log`). 기존 저장/탐색/준비 운동 검사에 보호자 관문·자동 단계 올림 끄기·설정 DB 재개·실제 획 미리보기·h-ㅏ 진도 미생성을 추가했다. 부팅53.6초/debug 빌드42.5초/검사19초이며 종료 후5580만 종료했다. 실제 기기·기존5554의 데이터를 사용하지 않는다. 실기기 마지막 검사 때 이 설정을 끈 뒤 기존 높은 세션 재진입/완료 기록과 미리보기의 스크롤·획 시범·동작 끄기도 확인한다.

최신 콘텐츠 보완 후 같은 격리 에뮬레이터에서 통합 **2개 통과**(`docs/review-rules-android-integration.log`). 만2세 탐색에서 힌트2회 후 두 번째 그림도 성공으로 저장되고 DB를 다시 열어 그대로 복원되는 검사를 추가했다. 기존 프로필/이동/준비 운동/DB 재개 검사도 통과했다. 앱 기본 데이터 대신 각 테스트의 고유한 별도 DB를 사용하며, 종료 후5580만 종료했다. 이는 실기기 청취/손가락/프레임/전체12화 검증이 아니다.

## 실행할 검증
1. `powershell -ExecutionPolicy Bypass -File tool/android.ps1 devices`로 Android 연결 확인.
2. 테스트용 에뮬레이터 ID를 확인한 뒤 `tool/android.ps1 test integration_test/app_flow_test.dart --device-id=<에뮬레이터ID> --timeout=120s` 실행. PowerShell에서는 옵션 값을 `=`로 전달한다. 테스트는 별도의 SQLite DB를 사용하며 실제 학습 데이터는 변경하지 않는다. debug 통합 검사에는 공유 릴리스 키가 필요하지 않다.
3. 한국어/영어 오프라인 TTS 언어팩 설치 및 비행기 모드에서 읽기 확인. A 이름과 Apple의 첫소리, ㄱ 이름과 가방, 1/하나 등 구분 검수.
4. 홈 → 세 과목 → 퀴즈 → 필기 → 그림 → 작품 → 보호자 확인을 가로/세로에서 실행.
5. 필기: 획 순서·역방향·짧은 획·멀티터치·취소·손 떨림·시범/애니메이션 끔·재시작 복원 확인.
6. 스토리: 12화 완주, 9화 모든 길, 7화 그림 저장, 힌트/도움 끔/반복 시도/쉬운 길, 화면 잠금 및 강제 종료 후 이어하기.
7. 그림: 도장/브러시/지우개/undo/redo/회전/저장/PNG 다시 열기, 저장 공간 부족과 보호자 삭제 확인.
8. 시간: 하루 누적 시간 유지, 백그라운드 제외, 종료 경계에서 쉬는 화면, 보호자 시간 조정, 다음 날 초기화.
9. 음성 반복 탭/페이지 전환/앱 일시 중지에서 겹치거나 이어서 나오지 않는지 확인.
10. `flutter run --profile`로 필기 및 그림 프레임/메모리 확인. 시스템 재부팅/서명 APK 새 설치·업데이트 확인.
