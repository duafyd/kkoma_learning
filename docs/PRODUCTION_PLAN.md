# 꼬마런닝 1.0 완성본 제작 계획

2026-11-28 · 저장소 `duafyd/kkoma_learning` · 진행 브랜치 `prototype/worksheet` · 실행 기준 [Godot 0.7 첫 화면](preview/play-menu-07.jpg)

## 완성본을 쓰는 모습

보호자가 갤럭시탭에 설치해 만 2·3·4·5세 중 아이의 연령을 한 번 고른다. 아이는 첫 화면에서 한글·영어·숫자를 독립적으로 고르거나 과일 가게 문을 열어 여러 과목의 주문을 함께 해결한다. 빵집 주문도 독립 가게 놀이로 만난다. 한 판이 끝나면 자기가 포장한 물건과 쓴 이름표가 진열된다. 다음 날에는 최근과 다른 주문을 만나고, 중간에 그만둔 판은 이어갈 수 있다. 보호자는 아이가 혼자 해 본 것과 도움을 받아 해 본 것을 확인할 수 있다.

| 제작 기준 | 1.0에 담을 경험 |
| --- | --- |
| 기기·언어 | 갤럭시탭 가로, 손가락 한 개, 오프라인 첫 실행. 한국어 UI에 영어 학습 대사를 넣는다. 현재 Godot 4.7.2와 arm64 Android 경로를 이어 쓴다. |
| 화면·소리 | 승인한 2D 모모, 맑은 중간 채도, 간결한 가게 배경과 동적인 표정·소품. 둥근 황갈색 한국 배. 첫 실행은 음성과 효과음 켜짐이며 이후 사용자의 선택을 기억한다. 현재 A 음성은 교체 가능한 대사 ID로 관리한다. |
| 콘텐츠 | 과일 가게·빵집 각각 네 연령 × 다섯 영역 × 두 기본 주문. 한글·영어·수학·관찰·규칙의 대사와 정답은 [80개 주문 원고](ORDER_CATALOG.md)에 있다. |
| 편성·쓰기 | 골고루 놀기 다섯 장, 과목별 세 장, 한글·영어·숫자 연필 서랍 세 장. 혼합 쓰기는 최대 한 장. 탭·선택적 끌기와 직접 쓰기·함께 쓰기를 지원한다. |
| 완료 산출물 | 오프라인으로 끝까지 플레이되는 서명 설치본, 실제 실행 화면, 빌드 소스와 버전, 콘텐츠 검수 결과, 실기기 검증 기록, 설치·업데이트 안내. 스토어 제출 여부와 시점은 별도 배포 결정이다. |

## 다음 작업

아래 인수 기준에 따라 실제 태블릿에서 첫 실행, 유음·무음 한 판, 두 가게의 이어하기와 만 5세 여러 획 쓰기를 검수한다. 기기가 확인되는 대로 모델과 Android 버전, 관찰한 문항 ID, 아이가 멈춘 위치를 인수인계에 남긴다. 문항·화면을 조정한 뒤 동일한 경로에서 재현한다. 0.7 APK와 정식 배포용 서명은 Android 설치 경로에 따라 호환 여부를 별도로 확인한다.

현재 장면과 범위는 [인수인계](HANDOFF.md), 활동별 목표와 준비 자료는 [주문 원고](ORDER_CATALOG.md)에 있다.

## 출시 인수 기준

| 확인 대상 | 재현과 통과 기준 | 남길 근거 |
| --- | --- | --- |
| 콘텐츠·쓰기 | 80개 ID와 세 장용 변형에 대해 정답·오답·도움·종료를 연다. 한글·영어·숫자의 요청 글자와 획, 표시 그림과 읽는 수량이 맞다. 직접 따라 그리기는 시작점·끝점만 누르면 미완료, 손을 떼었다 이어 그리면 완료된다. | 문항 ID별 결과, 수정 커밋, 쓰기 대표 화면 |
| 반복·복습 | 같은 연령·가게로 연속 두 판과 후보 소진 이후를 실행한다. 혼합 다섯 영역이 유지되고, 선택지가 있을 때 첫 과목·최근 주문을 바꾼다. 도움받은 목표가 이후 다른 예로 돌아온다. | 재현 가능한 판 순서·문항/변형 ID |
| 소리·동선 | 신규 설치는 음성·효과음 켜짐이다. 주문 도중 음소거, 다시 듣기/보기, 앱 전환, 복귀, 다음 장으로 가기를 확인한다. 영어 그림 단서를 본 경우와 듣고 해결한 경우가 구별된다. | 화면·재생·저장 결과 |
| 갤럭시탭·실사용 | 모델·Android 버전·화면 크기를 적는다. 만 2~3세와 4~5세가 첫 행동을 시작하는지, 손가락이 단서를 가리는지, 눌러 담기·끌기·쓰기에서 어디서 멈추는지 관찰한다. 막힌 장면은 같은 기기에서 수정 후 다시 본다. | 기기, 익명 연령대, 주문 ID, 관찰·수정·재확인 |
| 설치·복구·인도 | 비행기 모드 첫 실행과 두 가게 완주, 뒤로 가기·강제 종료·재실행, 대표 이전 버전에서의 데이터 처리, 배포 파일 재다운로드·서명 확인을 수행한다. 사용자에게 보여 줄 설치 경로에서 검증한다. | 버전·커밋·해시·서명 지문·설치 결과·다운로드 링크 |

0.7은 arm64 디버그 설치본이고 앱 ID는 `org.kkoma.prototype.applemarket`이다. 정식 서명과 기존 디버그 서명이 다르면 Android가 같은 앱 위에 설치하는 업데이트를 거부한다. 배포 경로 결정 시 기존 이용자용 설치·기록 이전 방법과 새 설치를 각각 시험한다. 비밀 키는 저장소 밖에서 관리한다. 배포 채널, 최종 서명 주체, 최종 목소리, 실제 태블릿 모델은 아직 결정·확인이 남아 있다. 현재 단계의 개발은 기록된 기준으로 진행할 수 있다.

## 다른 채팅에서 이어갈 때

README에서 바로 [인수인계](HANDOFF.md)를 연다. 이 문서는 전체 일정과 완료 조건, [제품 기획](PRODUCT_PLAN.md)은 교육·미술 방향, [출시 명세](RELEASE_SPEC.md)는 화면·편성 규칙, [주문 원고](ORDER_CATALOG.md)는 문항별 내용을 관리한다. 구현을 끝낸 작업 단위마다 인수인계 첫 부분에 **검증한 코드 커밋, 실행 가능한 범위, 검증 방법과 결과, 남은 일, 다음 작업**을 갱신한다. 새 채팅에서는 원격 브랜치 최신 상태와 마지막 검증 기록을 대조한 뒤 장부의 다음 묶음을 이어 간다.
