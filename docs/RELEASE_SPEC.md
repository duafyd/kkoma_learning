# 모모의 동네 · 첫 출시 제작 명세

[제품 기획과 연령별 학습 목표](PRODUCT_PLAN.md) · [현재 빌드와 인수인계](HANDOFF.md)

첫 제작 단원의 여섯 화면과 장면별 대본은 [과일 가게 첫 한 판](FRUIT_ROUND.md)에서 확인한다.

## 한 판을 시작하고 끝내는 길

| 화면 | 터치와 다음 화면 | 화면·소리 반응 |
| --- | --- | --- |
| 보호자 첫 설정 | 만 2·3·4·5세 중 하나를 고르고 시작한다. 연령은 나중에 보호자 메뉴에서 바꿀 수 있다. | 선택한 연령의 예시 주문 하나를 그림으로 보여 준다. 초기값은 기기당 아이 한 명이다. |
| 놀이 선택 | 첫 화면에 한글 놀이·영어 놀이·숫자 놀이·과일 가게를 각각 둔다. 과목을 누르면 해당 과목 세 장, 가게를 누르면 다섯 영역이 섞인 주문이 바로 시작된다. 빵집은 출시 제작 단계에 독립 가게로 추가한다. | 책·글자 블록·주판·과일 바구니를 사용한다. 각 버튼은 자기 진행 위치를 기억한다. |
| 과목 안 | ‘따라 쓰기’로 해당 과목의 쓰기 세 장에 들어가고 ‘세 장 놀기’로 돌아온다. 계속하기·다음 놀이·놀이 선택을 제공한다. | 과목 이름을 유지한다. 쓰기와 일반 놀이의 진행을 각각 보관한다. |
| 주문 한 장 | 그림 주문 → 시범 → 아이의 조작 → 가게에 결과 반영 → 다음 화살표. 주문 중 홈이나 Android 뒤로 가기는 멈춤 화면을 연다. | 주문 카드에 물건 그림과 짧은 말 한 줄을 싣는다. 한 장에 한 대상만 움직여 시선을 안내한다. 배경은 차분하게 유지한다. |
| 멈춤·이어하기 | 계속하기와 동네로 가기 중 고른다. 다시 열면 마지막 주문을 같은 보기로 제시한다. | 완료한 장과 안내 설정을 보존한다. 작성 중이던 장은 처음부터 다시 시도하고, 직전에 끝낸 장은 중복 집계하지 않는다. |
| 한 판 마무리 | 완성한 주문들이 진열대에 놓인다. ‘또 놀기’는 새 판, 집 그림은 동네로 연결한다. | 모모가 완성한 물건을 하나씩 짚어 준다. 아이가 누를 때까지 기다린다. |
| 보호자 메뉴 | 연령, 난이도, 음량 설정과 최근 놀이를 확인한다. | 최근 가게·목표·직접 해 본 활동·도움받은 활동을 짧게 보여 준다. 점수나 순위는 표시하지 않는다. |

## 제작할 주문

가게·연령별 실제 부탁, 보기와 완료 조건, 도움 연출은 [80개 주문 원고](ORDER_CATALOG.md)에 있다. 현재 단계와 개발 순서는 [완성본 제작 계획](PRODUCTION_PLAN.md)에서 갱신한다.

두 가게에서 각각 다섯 영역을 다루고 네 연령별로 난이도를 작성한다. 출시 최소 분량은 **40개 조합 × 서로 다른 주문 두 개 = 80개 기본 주문**이다. 물건 위치나 색만 바꾼 보기는 분량에서 제외한다. 아래 두 활동을 각 가게의 소품으로 제작하고, 연령별 목표는 제품 기획 표를 적용한다.

| 영역 | 과일 가게의 두 활동 | 빵집의 두 활동 |
| --- | --- | --- |
| 한글 | 모모가 찾는 과일 고르기 / 과일 이름표 쓰기 | 그림에 빵 이름표 붙이기 / 진열대 이름표 쓰기 |
| 영어 | 영어 주문 그림 찾기 / 과일 상자 첫 글자 쓰기 | 영어 메뉴와 빵 짝짓기 / 봉투에 첫 글자 쓰기 |
| 수학 | 주문 수량 담기 / 바구니 수량표 쓰기 | 봉투에 부족한 빵 채우기 / 봉투에 수량 쓰기 |
| 관찰 | 자른 단면과 과일 짝짓기 / 견본과 같은 상자 찾기 | 빵 실루엣 짝짓기 / 견본의 위치대로 진열하기 |
| 규칙 | 과일 줄의 다음 칸 채우기 / 두 줄 중 견본과 같은 줄 찾기 | 쿠키 줄 이어 놓기 / 무늬 순서가 바뀐 칸 찾기 |

만 2세의 쓰기 자리는 이름표 바탕에 선을 긋거나 수량 하나에 점 하나를 찍는 활동으로 바꾼다. 만 2세 규칙은 같은 모양을 한 번 더 놓는 단계에서 시작한다. 영어 첫 글자를 배우기 전에는 이름을 들으며 물건의 둥근 부분이나 곧은 부분을 따라 그린다. 각 주문에는 사용할 소품, 나이, 목표, 보기, 정답 또는 허용 경로, 한 줄 대사, 무음 시범, 도움 단계, 완료 연출을 함께 기록한다.

**따라 그리기 서랍**은 선택한 과목·연령에 맞는 서로 다른 모양 세 장을 제공한다. 예를 들어 만 4세 수학에는 1·2·3, 한글에는 ㄱ·ㄴ·ㅁ, 영어에는 L·O·I를 둔다. 세 장이 채워질 때까지 추가 모양을 제작한다. 80개는 기본 주문 수이고 서랍의 모양 변형은 별도로 검수한다. 한글은 획의 순서와 자모 배치, 영어는 대소문자와 실제 단어의 첫 글자, 숫자는 그날 수량과의 일치를 대본·그림에서 함께 확인한다.

서랍의 첫 세 장은 아래 순서로 제작한다. 같은 글자를 여러 장에 걸쳐 쓰는 대신, 한 글자를 크게 완성하고 가게 안에서 무엇에 쓰였는지 보여 준다.

| 연령 | 한글 이름표 | 영어 그림 카드 | 숫자 주문표 |
| --- | --- | --- | --- |
| 만 2세 | 이름표에 가로·세로·둥근 길 긋기 | 물건 그림 속 곧은 길·굽은 길·둥근 길 긋기 | 한 자리에 점 찍기·두 자리에 점 찍기·물건 하나까지 선 잇기 |
| 만 3세 | ㅡ·ㅣ·둥근 선 | 긴 세로선·짧은 가로선·둥근 선 | 1 긋기·두 점 잇기·2의 굽은 윗부분 따라가기 |
| 만 4세 | ㄱ·ㄴ·ㅁ | L·O·I | 1·2·3 |
| 만 5세 | 배·감·잣처럼 한 글자로 된 이름 | A·B·P | 3·4·5 |

글자 카드는 실제 그림과 짝지어 제작한다. 예를 들어 만 5세 과일 가게의 한글 카드는 배·감·잣, 빵집 카드는 빵·콩·팥을 사용할 수 있다. 물건 이름을 처음 듣는 아이에게는 완성 전후에 같은 그림을 함께 보여 준다.

## 한 판을 고르는 규칙

1. 독립 과목은 선택 과목·나이·쓰기 모드로, 가게는 장소·나이로 후보를 좁힌다. 혼합은 다섯 영역 한 장씩, 과목 모드는 세 장이다. 먼저 활동 방식을 고른 뒤 목표와 물건을 뽑는다. 최근 판이 관찰로 시작했다면 다른 영역으로 연다.
2. 혼합에서는 쓰기를 최대 한 장만 고른다. 직전 주문과 같은 조작이 연속하면 다른 후보를 먼저 찾는다. 보기를 섞은 것만으로 새 주문으로 간주하지 않는다.
3. 기본 주문이 두 개뿐인 과목에서 세 장을 요청하면 세 번째는 수량·목표 글자·규칙을 바꾼 사전 검수 변형을 쓴다. 변형까지 소진하면 가장 오래전에 한 주문을 쓴다. 한글 이름 찾기와 영어 이름 찾기처럼 손동작이 비슷한 활동 사이에는 가능한 한 담기나 줄 만들기를 넣는다.
4. 도움받은 목표는 다음 판부터 다른 예로 다시 낸다. 음소거 중 듣기 문항은 그림 대응으로 전환한다. 중간에 소리를 꺼도 주문 수나 남은 장 수가 바뀌지 않는다.
5. 한 판을 시작할 때 고른 순서와 보기를 기기에 저장한다. 완료 처리와 다음 장 위치는 함께 저장한다. 다시 열거나 완료 애니메이션을 두 번 눌러도 같은 주문은 한 번만 센다.

## 제작 자산과 확인 항목

- 승인된 모모의 비율·표정과 중간 채도의 가게 그림을 메뉴까지 사용한다. 장소별 배경 한 장, 물건 네 종류 이상, 이름표·수량표, 큰 시작점과 끝점, 시범 손, 모모의 인사·부탁·가리키기·완료 동작을 준비한다. 글자·숫자 경로는 배경 이미지와 분리해 손가락 자취와 겹쳐 그린다.
- 주문·힌트·개수·완료 대사는 각각 자막, 음성 파일, 시범 동작과 연결한다. A 목소리는 임시 음성이다. 소리를 끄면 재생 중인 말과 효과음을 멈춘다. 소리가 끝나기 전에 아이가 행동해도 주문을 처리한다.
- Godot의 공통 주문 화면은 고르기, 담기·옮기기, 배열하기, 따라 그리기를 담당한다. 가게·문항 데이터에서 사용할 조작과 소품을 지정한다. 보호자 설정과 현재 판은 기기에 저장하고 오프라인으로 첫 실행부터 마무리까지 가능하게 한다.

| 제작 순서 | 완료를 확인하는 방법 |
| --- | --- |
| 1. 과일 가게 한 판 | 동네에서 한글·영어·수학·관찰·규칙을 각 한 번 하고 돌아온다. 수학은 담기와 숫자 2 쓰기를 각각 실행한다. |
| 2. 쓰기와 연령 조정 | 선, 낱자, 영어 대문자, 숫자를 각각 실기기에서 그린다. 손 떼기·길 이탈·여러 획·시범 도중 터치·함께 완성을 시험하고 진행 상태와 도움 기록을 확인한다. |
| 3. 두 가게 완성 | 40개 조합의 기본 주문 두 개씩을 열어 목표·무음 안내·정답·도움을 확인한다. 각 과목 세 장과 연속 혼합 두 판에서 위 편성 규칙을 검사한다. |
| 4. 설치·사용성 검토 | 대상 갤럭시탭의 모델과 Android 버전을 기록한다. 가로 화면 양끝의 버튼과 손가락 가림, 음량 0, 비행기 모드, 앱 전환·재실행, 기존 0.4에서 업데이트 후 설정 복원을 확인한다. |
| 5. 출시 판단 | 만 2~3세와 4~5세가 각각 첫 주문과 쓰기 주문을 보호자가 대신 조작하지 않고 시도하는 모습을 관찰한다. 시범을 다시 보거나 도움으로 마친 경우를 구분한다. 행동을 시작할 단서가 없거나 진행이 막히는 장면은 수정 후 다시 관찰한다. 보호자에게 제공할 빌드에서 최종 음성 또는 임시 음성 유지 결정을 기록한다. |

실기기 관찰 전에는 연령별 난이도와 선 폭을 제작 기본값으로 사용한다. 관찰 뒤에는 어떤 기기에서 어느 활동이 막혔고 무엇을 바꿨는지 인수인계 문서에 남긴다.
