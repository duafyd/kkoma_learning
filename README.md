# 꼬마런닝 · 오늘의 가게

만 2~5세 아이가 모모와 과일 가게·빵집을 운영하며 한글·영어·수학·관찰·규칙을 배우는 갤럭시탭용 오프라인 학습 앱입니다. 1.0 후보에서 네 연령과 두 가게의 128개 활동을 플레이할 수 있습니다.

**새 채팅·다른 모델의 시작점**은 [현재 상태와 인수인계](docs/HANDOFF.md)입니다. [1.0 완성본 제작 계획](docs/PRODUCTION_PLAN.md) · [80개 기본 주문 원고](docs/ORDER_CATALOG.md) · [제품 기획](docs/PRODUCT_PLAN.md) · [과일 가게 콘티](docs/FRUIT_ROUND.md)

## 갤럭시탭에서 놀이 고르기

[1.0-rc1 APK 받기 · 갤럭시탭 arm64](https://raw.githubusercontent.com/duafyd/kkoma_learning/prototype/worksheet/trial/momo-apple-arm64.apk) · [놀이마당](docs/preview/play-menu-07.jpg) · [빵집](docs/preview/bakery-07.jpg) · [한글 따라 쓰기](docs/preview/writing-07.jpg)

처음에는 보호자가 만 2~5세 중 아이의 연령을 선택합니다. 놀이마당에서 그림 버튼 하나를 누르면 해당 놀이가 열립니다.

| 버튼 | 한 판에서 하는 일 |
| --- | --- |
| 한글 놀이 | 한글 이름표 고르기, 한국어 이름을 듣고 그림 찾기, 자모 쓰기 |
| 영어 놀이 | 영어 주문 듣고 그림 고르기, 그림과 단어 연결하기, 알파벳 쓰기 |
| 숫자 놀이 | 물건을 세고 숫자 고르기, 숫자에 맞는 묶음 찾기, 숫자 쓰기 |
| 과일 가게 | 한글·영어·수학·관찰·규칙 다섯 주문입니다. 과일 담기는 탭과 끌어놓기를 지원합니다. |
| 빵집 | 빵과 쿠키로 같은 다섯 영역을 놉니다. 봉투에 담기, 배열, 그림자와 모양 맞추기가 나옵니다. |

세 과목은 각각 세 장씩 진행합니다. 상단 **따라 쓰기**를 누르면 그 과목의 글자나 숫자만 세 장 이어 쓰고, **세 장 놀기**를 누르면 일반 놀이로 복귀합니다. ‘잠깐 쉬기 → 놀이 선택’으로 나와 다른 놀이를 고를 수 있습니다. 놀이별 진행 위치와 선택한 쓰기 모드는 기기에 저장됩니다. 과일 가게도 이전 0.5의 진행 위치부터 이어집니다.

처음에는 모모의 A 음성과 효과음이 켜져 있습니다. 소리를 끄면 듣고 고르는 장에서 그림 단서를 볼 수 있고, 다음 실행에도 선택을 기억합니다. 보호자 메뉴에서 나이와 최근 놀이 기록을 볼 수 있습니다. 나이를 바꾸면 시작하는 다음 판부터 적용합니다.

Godot 4.7.2에서 [godot/project.godot](godot/project.godot)을 가져와 **F5(프로젝트 실행)** 로 시작합니다. 설치·업데이트와 재빌드 방법은 [Android 배포 안내](docs/ANDROID_RELEASE.md)에 있습니다.

## 이전 브라우저 실험판 실행

[프로토타입 ZIP 받기](https://github.com/duafyd/kkoma_learning/archive/refs/heads/prototype/worksheet.zip). 압축을 풀고 브라우저로 `index.html`을 엽니다. 별도 패키지 설치나 빌드 과정 없이 동작합니다. 로컬 서버에서 확인할 때는 이 디렉터리에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`을 엽니다.

1. 보호자가 연령을 고르고 아이가 과일 가게나 빵집을 선택합니다.
2. **골고루 놀기**는 한글·영어·수학·관찰·규칙을 하나씩 섞은 다섯 장입니다. 과목을 직접 고르면 세 장입니다.
3. 틀렸을 때 나오는 도움말과 **다시 듣기**를 확인합니다. 만 5세 수학에서는 물건을 담거나 덜어낸 다음 **상자 보내기**를 누릅니다.
4. **새 주문으로 또 놀기**를 눌러 다음 판을 비교합니다. 같은 브라우저에서 최근 문항 조합을 기억합니다. 한국어·영어 발음은 기기에서 제공하는 음성을 사용합니다.
